# Employee Management System

A simple web-based Employee Management System built using "Java, Spring Boot and Thymeleaf"

## Features
- Add new employees
- View all employees
- Delete employee records
- Manage employee details such as name, email, department, and salary

## Technologies Used
- Java
- Spring Boot
- Thymeleaf
- HTML and CSS
- Maven

## Getting Started

1. Clone the repository.
2. Configure your database connection in "application.properties".
3. Run the application using your IDE or Maven.
4. Open "http://localhost:8080/employees" in your browser.
